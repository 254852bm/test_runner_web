## Начало работы

TestRun — веб-приложение, доступное по адресу [https://testrun.pro](https://testrun.pro).  
Ничего скачивать не нужно — работайте прямо в браузере.

**Минимальные требования:**
- Современный браузер (Chrome, Firefox, Edge, Safari).
- Подключение к интернету.

---

## Регистрация и вход

### Регистрация
1. Откройте [testrun.pro](https://testrun.pro).
2. Нажмите **«Зарегистрироваться»**.
3. Укажите email, пароль и (опционально) название компании.
4. Нажмите **«Зарегистрироваться»**.

### Вход
1. Откройте [testrun.pro](https://testrun.pro).
2. Нажмите **«Войти»**.
3. Введите email и пароль.

## Интерфейс

После входа вы попадаете на **Dashboard**.  
Слева — боковое меню с разделами:
- 🏠 **Dashboard** — общая статистика.
- 📁 **Проекты** — список ваших проектов.
- 🌙 **Тема** — переключение светлой/тёмной темы.
- 🚪 **Выход** — выход из аккаунта.

## Проекты

### Создать проект
1. Перейдите в **Проекты**.
2. Нажмите **«+ Создать проект»**.
3. Введите название.
4. Нажмите **«Создать»**.

### Открыть проект
Кликните на название проекта в списке.

### Удалить проект
Нажмите кнопку **🗑️ Удалить** рядом с проектом.  
⚠️ Внимание: удаляются все тесты и прогоны проекта.

## Тест-кейсы

### Создать тест-кейс
1. Откройте проект.
2. Нажмите **«+ Добавить тест»**.
3. Заполните:
   - **Заголовок** — краткое название.
   - **Предусловие** — что должно быть выполнено до теста.
   - **Шаги** — каждое действие отдельно + ожидаемый результат.
4. Нажмите **«Сохранить»**.

### Редактировать тест-кейс
Нажмите **✏️ Редактировать** на странице тест-кейса. При сохранении создаётся **новая версия**.

### История версий
На странице тест-кейса отображается список всех версий с датой и автором.

## Прогон тестов

### Запустить один тест
На странице тест-кейса нажмите **«▶ Запустить этот тест»**.

### Запустить все тесты проекта
На странице проекта нажмите **«▶ Запустить все»**.

### Пошаговая оценка
Для каждого шага:
1. Выберите статус:
   - ✅ **Пройден** — шаг выполнен, результат совпал.
   - ❌ **Не пройден** — есть отклонение.
   - ⏭️ **Пропущен** — шаг не выполнялся.
2. При необходимости добавьте комментарий.
3. Нажмите **«Сохранить результат теста»**.

После сохранения вы перейдёте к следующему тесту (или к статистике, если тестов больше нет).

## Отчёты

### Экспорт PDF
1. Откройте страницу статистики после прогона.
2. В блоке **«📄 Экспорт отчёта в PDF»**:
   - Укажите период (опционально).
   - Нажмите **«📄 Скачать отчёт»**.
3. PDF скачается автоматически.

**Если поля пустые** — в отчёт попадут все прогоны проекта.

## История

Раздел **📜 История** показывает все прогоны проекта с шагами и комментариями.  
Используйте фильтр по датам, чтобы найти нужный период.

## Dashboard

Карточки на Dashboard показывают:
- ✅ Пройдено
- ❌ Не пройдено
- ⏭️ Пропущено
- 📦 Всего

Клик по карточке фильтрует прогоны по статусу.
