# 🧪 TestRun — простой тест-раннер для QA-команд

**TestRun** — это лёгкий веб-инструмент для ручного тестирования, управления тест-кейсами и отчётности.  
Подходит для небольших IT-команд, фрилансеров и учебных курсов по QA.

🔗 **Демо:** [https://testrun.pro](https://testrun.pro)

---

## ✨ Возможности

- 📁 **Проекты и тест-кейсы** — структурируйте тесты по проектам.
- 🧩 **Пошаговые тесты** — каждый шаг имеет своё действие и ожидаемый результат.
- ✅ **Прогон с пошаговой оценкой** — PASS / FAIL / SKIP для каждого шага.
- 📜 **История прогонов** — все результаты сохраняются.
- 📊 **Dashboard** — статистика по проектам, диаграммы PASS / FAIL / SKIP.
- 📄 **Экспорт в PDF** — отчёты с фильтром по периоду, поддержка кириллицы.
- 🔄 **Версионирование тест-кейсов** — история изменений.
- 🌙 **Светлая и тёмная темы**.
- 🔐 **Регистрация и авторизация** — приватные проекты для каждого пользователя.

## 🚀 Быстрый старт

1. Зарегистрируйтесь на [testrun.pro](https://testrun.pro).
2. Создайте проект.
3. Добавьте тест-кейс с шагами и ожидаемыми результатами.
4. Запустите прогон, отметьте статусы шагов.
5. Скачайте PDF-отчёт за нужный период.

📖 **Подробнее:** [Руководство пользователя](docs/user-guide.md)

## 🛠 Технологии

- **Backend:** Python 3.12, Flask, SQLAlchemy
- **База данных:** SQLite (легко мигрировать на PostgreSQL)
- **Frontend:** HTML, Bootstrap 5, JavaScript
- **PDF:** ReportLab
- **Развёртывание:** Gunicorn + Nginx, Ubuntu VPS
- **Хостинг:** [testrun.pro](https://testrun.pro)
