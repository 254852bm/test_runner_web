# 🧪 TestRun — система управления ручным и автоматизированным тестированием

**TestRun** — веб-приложение для организации QA-процессов: проекты, тест-кейсы, ручные прогоны, история результатов, отчёты и интеграция с автотестами.

🔗 **Сайт:** [https://testrun.pro](https://testrun.pro)

## Возможности

- **Проекты и тест-кейсы** — организация тестирования по проектам.
- **Шаги тест-кейсов** — действия и ожидаемые результаты для каждого шага.
- **Ручные прогоны** — статусы PASS / FAIL / SKIP, комментарии и результаты шагов.
- **История прогонов** — сохранение результатов и просмотр предыдущих запусков.
- **Версионирование тест-кейсов** — история изменений содержания теста.
- **Параметризация ручных тестов** — повторное использование одного тест-кейса с разными наборами входных данных, например `{{login}}`, `{{password}}`, `{{base_url}}`.
- **Наборы тестовых данных** — колонки и строки, включение/отключение строк, одиночный и последовательный запуск.
- **Защита секретов тестовых данных** — отдельное шифрование секретных значений и ограниченная выдача через API.
- **API для автоматизации** — получение наборов/строк и отправка результатов автотестов, в том числе из Java + JUnit 5 + Selenide.
- **Dashboard и PDF** — статистика прогонов и отчёты с поддержкой кириллицы.
- **Скриншоты** — вложения к ожидаемым результатам и комментариям шагов.
- **Личный кабинет и поддержка** — профиль и переписка по обращениям.
- **Администрирование** — управление доступом пользователей и обработка обращений уполномоченным администратором.
- **Светлая и тёмная темы**, адаптивная навигация.

> Примечание: параметризация и связанные с ней API/шифрование описаны в feature-ветке и должны пройти ручную приёмку на изолированной тестовой копии до выпуска в production.

## Быстрый старт пользователя

1. Зарегистрируйтесь на [testrun.pro](https://testrun.pro).
2. Создайте проект и тест-кейс.
3. Добавьте шаги, действия и ожидаемые результаты.
4. Запустите ручной прогон и укажите статусы шагов.
5. Просмотрите историю и при необходимости экспортируйте PDF.

## Технологии

- **Backend:** Python, Flask, SQLAlchemy.
- **База данных:** SQLite в текущем развёртывании.
- **Frontend:** Jinja2, HTML, Bootstrap, CSS и JavaScript.
- **PDF:** ReportLab.
- **Секретные тестовые данные:** Fernet через библиотеку cryptography.
- **Production-развёртывание:** Gunicorn + Nginx на Ubuntu VPS.
